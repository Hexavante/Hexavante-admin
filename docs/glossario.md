# Glossário — Hexavante Admin

Documento de referência dos termos usados no código e nas telas.

---

| Termo | Significado |
|-------|-------------|
| Painel | Este app (`painel.hexavante.com.br`), separado do app principal |
| Sessão admin | `hx_admin_session`, 30 dias deslizantes, só para moderação |
| Fila | Conteúdo aguardando curadoria (cursos, tutoriais, categorias, instrutores) |
| Correção | Avaliação manual de resposta dissertativa |
| Broadcast | Notificação em massa para a base |
| Booster global | Multiplicador temporário de XP/moedas para todos |
| Terminal | CLI web com os mesmos comandos da UI |
| Spotlight | Busca rápida `Ctrl+K` por usuários e conteúdo |
